# GPM Sign & Verify

Modern digital document management and verification platform for Griya Pustaka Mandiri.

## Current foundation
- Responsive public landing page
- Verification entry UI
- Admin dashboard prototype
- Document list prototype
- Navigation shell and reusable visual components

## Run locally
```bash
npm install
npm run dev
```

## Important
This initial UI prototype is not a PSrE-certified electronic signature system. Signing, identity verification, QR verification, document hashing, audit logging, and backend authentication are not yet connected to production services.
